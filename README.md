۱. **وظایف مستقل در مرورگر وب:**
* رابط کاربری و حلقه رویداد (UI & Event Loop)
* موتور رندرینگ و چیدمان صفحه (Rendering & Layout Engine)
* پشته شبکه و سوکت‌ها (Network I/O)
* موتور اجرای جاوااسکریپت (JS Engine)
* رمزگشایی چندرسانه‌ای (Media Decoding)
* مدیریت کش و ورودی/خروجی دیسک (Disk I/O & Caching)

۲. **وظایف قابل پیاده‌سازی در قالب نخ‌های مختلف (Threads):**
* نخ اصلی رابط کاربری (Main UI Thread)
* نخ رندرینگ/کامپوزیتور (Compositor Thread برای اسکرول و انیمیشن‌ها)
* نخ‌های کارگر شبکه (Network I/O Worker Threads برای دانلود فایل‌ها و ریکوئست‌ها)
* نخ موتور جاوااسکریپت و وب‌ورکرها (JS Engine & Web Workers)
* نخ بازیافت حافظه (Garbage Collector Thread)

۳. **مشکل تغییر هم‌زمان داده مشترک توسط دو نخ:**
* **شرایط رقابتی (Race Condition):** تداخل در دستورات `Read-Modify-Write` به دلیل غیراتمیک بودن عملیات.
* **ناسازگاری و مخدوش شدن داده‌ها (Data Inconsistency / Corruption):** بازنویسی یا از بین رفتن تغییرات یک نخ توسط نخ دیگر.
* **خطاهای سیستم‌عاملی و کرش:** بروز رفتارهای پیش‌بینی‌ناپذیر، خطاهای حافظه (مانند Segmentation Fault) و از کار افتادن برنامه.

۴. **راهکارهای جلوگیری از این مشکل:**
* **موتکس و قفل‌ها (Mutex / Locks):** ایجاد انحصار متقابل (Mutual Exclusion) برای ورود به بخش بحرانی کد.
* **عملیات اتمیک (Atomic Operations & CAS):** استفاده از دستورات سخت‌افزاری پردازنده و متغیرهای اتمیک (Lock-Free) برای تغییر امن داده‌ها.
* **سمافورها (Semaphores):** مدیریت دسترسی هم‌زمان به استخری از منابع محدود.
* **ارسال پیام (Message Passing / Actor Model):** اجتناب از اشتراک مستقیم حافظه و تبادل داده بین نخ‌ها از طریق صف‌های ایمن (Channels).
